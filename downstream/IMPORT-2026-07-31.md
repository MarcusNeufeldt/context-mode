source composition. No minified bundle was hand-edited.

## Downstream integration hardening

The combined patch exposed test assumptions that were hidden on individual PR
branches:

- `hooks/find-bun.mjs` now uses `path.posix` or `path.win32` according to its
  injected platform, making the pure resolver testable across operating
  systems.
- #1009's process-tree tests now use Node for the spawned tree, exercising
  Windows and POSIX cancellation instead of requiring Bash syntax.
- OpenCode coercion tests now expect the correct empty-project handler error.
  #888's per-database isolation removed the accidental cross-project indexed
  state those tests had relied on.
- #898 received a direct oversized Markdown emoji regression, including
  dangling-surrogate and replacement-character checks.
- The `ctx_purge` source guard now asserts #888's per-database map cleanup
  rather than the removed `_store` singleton.
- One spawned-server test now waits for child exit before deleting its Windows
  working directory, avoiding an `EPERM` cleanup race.
- A reusable real-stdio smoke harness was added at
  `downstream/smoke/mcp-runtime-smoke.mjs`.
